Habilidade Nível Descrição
HTML iniciante HTML é a linguagem de marcação usada para criar a estrutura de páginas web. Com HTML, você pode definir elementos como títulos, parágrafos, links, imagens e muito mais. É a base para o desenvolvimento web e é essencial para qualquer pessoa interessada em criar sites ou aplicativos web.
CSS Intermediário CSS é a linguagem de estilo usada para definir a apresentação de páginas web. Com CSS, você pode controlar a disposição, cores, fontes e outros aspectos visuais dos elementos HTML.
JavaScript basico JavaScript é uma linguagem de programação usada para criar interatividade em páginas web. Com JavaScript, você pode adicionar funcionalidades como validações de formulários, animações e manipulação do DOM.
